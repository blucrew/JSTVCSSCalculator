General

Root Element

All overlays are Single Page Applications rendered into #root. The commonly assumed #application does not exist.

/* Always start with this reset */
html, body, #root { background: transparent !important; }
OBS note: Without this reset, the browser source renders a solid black or dark-grey box instead of a transparent overlay.

Inline Styles

Joystick's JavaScript injects style="color: rgb(...)" and style="width: X%" directly onto elements. Standard CSS rules lose to inline styles — always use !important.

Specificity tip: For stubborn inline styles, use attribute selectors like div.scrollable.text-3xl[style] to maximise specificity.

Tip Goal / Milestone Goal Bar Confirmed

Confirmed from v2 bundle + OBS live DOM. The old bg-pink-200 track selector is a v1 class and no longer exists.

DOM structure

All three elements — track, fill, and label — share the same parent. The label is a direct child of the track.

<div class="w-full overflow-hidden rounded-full border-2" style="...">  <!-- track -->
  <div class="absolute inset-0" style="width: X%; background: ..."></div>   <!-- fill -->
  <div class="relative z-10 ...">Goal Name · X% · amount/total</div>       <!-- label -->
</div>
ElementSelectorNotes
Progress track div.w-full.overflow-hidden.rounded-full.border-2[style] The [style] attribute selector boosts specificity to beat Joystick's JS-injected inline styles. Contains fill and label as direct children.
Progress fill div.w-full.overflow-hidden.rounded-full.border-2 > div.absolute width and background are both set inline by JS. Width animates from 0–100% as the goal progresses. Override both with !important.
Label text
(title · % · amount)		 div.w-full.overflow-hidden.rounded-full.border-2 > div.relative Physically inside the track div. By default it renders inside the bar. See Label Position below to move it outside.

Label Position — Inside the bar (default)

The label renders inside the track. Keep overflow: hidden so the fill is clipped by the track's rounded corners.

/* Track */
div.w-full.overflow-hidden.rounded-full.border-2[style] {
  background: rgba(0,0,0,0.7) !important;
  border: 2px solid #555 !important;
  overflow: hidden !important;
}

/* Fill */
div.w-full.overflow-hidden.rounded-full.border-2 > div.absolute {
  background: linear-gradient(90deg, #00d2ff, #00ff99) !important;
  background-size: 100vw 100% !important;
  background-position: left center !important;
}

/* Label */
div.w-full.overflow-hidden.rounded-full.border-2 > div.relative {
  font-family: 'Your Font', Impact, 'Arial Black', sans-serif !important;
  font-size: 0.85rem !important;
  white-space: nowrap !important;
  color: #ffffff !important;
}

Label Position — Above or Below the bar

The label is physically inside the track in the DOM, so moving it outside requires a CSS-only trick: set overflow: visible on the track (so the label can escape) and give the fill its own border-radius (so it clips itself instead of relying on the parent).

Why the explicit height? Once the label is positioned absolutely, it's out of normal flow and no longer contributes to the track's height. Without height: 1.75rem the track collapses to 0px.
/* Track — overflow:visible lets the label div escape */
div.w-full.overflow-hidden.rounded-full.border-2[style] {
  background: rgba(0,0,0,0.7) !important;
  border: 2px solid #555 !important;
  overflow: visible !important;     /* key change */
  position: relative !important;
  height: 1.75rem !important;       /* explicit height since label is out of flow */
}

/* Fill — self-clips since parent overflow is now visible */
div.w-full.overflow-hidden.rounded-full.border-2 > div.absolute {
  background: linear-gradient(90deg, #00d2ff, #00ff99) !important;
  background-size: 100vw 100% !important;
  background-position: left center !important;
  border-radius: 9999px !important; /* pill shape at any progress % */
}

/* Label — ABOVE the bar */
div.w-full.overflow-hidden.rounded-full.border-2 > div.relative {
  font-family: 'Your Font', Impact, 'Arial Black', sans-serif !important;
  font-size: 0.9rem !important;
  white-space: nowrap !important;
  text-align: center !important;
  color: #ffffff !important;
  position: absolute !important;
  left: 0 !important; right: 0 !important;
  bottom: calc(100% + 6px) !important;  /* swap to top: calc(100% + 6px) for below */
  top: auto !important;
}

For Below the bar, swap to top: calc(100% + 6px) !important; bottom: auto !important;

Custom Fonts

Google Fonts via @import

Works in OBS's embedded Chromium. Occasional flicker on first load while the SPA initialises. Always include a system font fallback.

@import url('https://fonts.googleapis.com/css2?family=Permanent+Marker&display=swap');

/* font-family stack: web font → bold system fallback → generic */
font-family: 'Permanent Marker', Impact, 'Arial Black', sans-serif !important;

Local Font via @font-face

More reliable if the Google Fonts import occasionally fails. Font must be installed on the machine running OBS.

@font-face {
  font-family: 'Permanent Marker';
  src: url('C:/Windows/Fonts/PermanentMarker-Regular.ttf');
}
Note: Courier New is a system font — do not attempt to load it from Google Fonts, it will be blocked by CORB.
