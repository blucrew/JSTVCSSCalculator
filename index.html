Joystick.TV CSS Styler

How to use:
1. Get your overlay URL from Joystick.TV Overlays.
2. In OBS: add a Browser Source → paste the overlay URL.
3. Pick your overlay type here & customize.
4. Copy the CSS → Browser Source → Custom CSS → Paste → Refresh cache.
